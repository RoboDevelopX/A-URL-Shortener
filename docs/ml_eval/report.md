## Limitations

See [docs/ML.md](../ML.md#limitations). In short: the dataset is old and noisy, the benign class is dominated by a few large sites, lexical features cannot see page content or domain age, and an attacker who knows the features can craft URLs that look benign. Treat these numbers as an upper bound on real-world performance.
